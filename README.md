 # To-Do-Liste in Python

Ein kleines Konsolenprogramm zur Verwaltung von Aufgaben. Die Aufgaben werden in einer JSON-Datei gespeichert und bleiben auch nach dem Beenden erhalten.

## Funktionen

- Aufgaben anzeigen
- Neue Aufgabe hinzufügen
- Aufgabe als erledigt markieren
- Aufgabe löschen
- Dauerhaftes Speichern in `tasks.json`
- Fehlerbehandlung bei ungültigen Eingaben

## Starten

Voraussetzung: Python 3 ist installiert.

bash
python todo.py


## Bedienung

Nach dem Start erscheint ein Menü:


1) Anzeigen  2) Hinzufügen  3) Erledigt  4) Löschen  5) Beenden


Gib die Nummer der gewünschten Aktion ein und bestätige mit Enter.

- Python 3
- JSON (Speicherung der Daten)
